How the score is built

1 · Hard gate (rules, no LLM)Python in skills/projects/work and an AI anchor (LLM, RAG, agents, framework) inside a project or job entry. Skills-list-only AI and AI coding assistants (Copilot, Cursor) don't count.
2 · AI depth, per projectEach project is profiled for capabilities — retrieval, agents/tools, framework, state, evaluation, data pipeline, backend, shipped impact. Best project counts fully, the next ones at 30% / 10%.
3 · Penalties are ledger linesThin LLM wrappers (an API call with no retrieval, tools, state, eval or pipeline) and tutorial-style entries subtract points with the quote that triggered it.
4 · Context-weighted rubricBackend, cloud and engineering signals earn full points in projects/jobs, 40% in a skills list, 25% in certifications — so keyword lists can't win.
5 · GitHub, max 10Recency of latest original push (0–5) + recently maintained Python/AI repos (0–5). Missing or private GitHub is recorded, never fatal.
6 · Optional LLM reviewerSchema-validated, may move AI depth by ±6 at most, and every quote it cites is checked against the resume — invented quotes void its adjustment.
